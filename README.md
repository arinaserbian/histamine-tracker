# Гистамин-трекер

Личное приложение (PWA): расписание приёма препаратов, дневник гистамина в баллах и база продуктов.

- `index.html`, `app.js` — приложение. База продуктов и схема лечения хранятся только в закрытой базе Supabase.
- `config.js` — адрес проекта Supabase и publishable key.
- `supabase/schema.sql` — таблицы и правила доступа (RLS).
- Схема лечения хранится только в базе и видна после входа по почте; в репозитории личных данных нет.
